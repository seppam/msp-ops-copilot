# New Hire Laptop Provisioning SOP

## Standard process
1. Confirm the start date and job role. Request at least 3 working days of notice.
2. Check stock for a standard laptop. If none, raise a purchase request, typical lead time 5 working days.
3. Image the laptop with the standard build, then install role-specific software such as the accounting application.
4. Create the user account and email, and enrol the device in management.
5. Hand over on the start date and record the asset tag.
